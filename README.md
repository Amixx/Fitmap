# FitMap

Latviska garderobes un tērpu plānošanas lietotne.

## Darbināt lokāli

```sh
bun install
bun run dev
```

Garderobes saturs atrodas [`src/data/wardrobe.json`](src/data/wardrobe.json), bet attēli — `public/images/`. Izmaiņas var pārbaudīt ar `bun run check` un `bun run build`.

## GitHub Pages

Atver [Pages iestatījumus](https://github.com/Amixx/Fitmap/settings/pages) un pie **Build and deployment → Source** izvēlies **GitHub Actions**. Pēc tam katrs `main` atjauninājums automātiski publicēs lietotni.
